Ask a question

Create a new question on-chain. Anyone can bond ETH on an answer. The final unchallenged answer after the dispute window closes becomes the result.

After each new answer, this window resets. The last unchallenged answer when the window expires is the result. Longer windows give more time to correct mistakes.
